# Auth & Project Ownership Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GitHub OAuth login via django-allauth; users see only their own projects; write endpoints enforce ownership.

**Architecture:** Session-based auth (HttpOnly cookie). Django-allauth handles GitHub OAuth callback and session creation. A thin `AuthContext` in React fetches `/api/auth/me/` on load to gate routes. All graph API endpoints require authentication; write endpoints additionally check `request.user == pm.owner`.

**Tech Stack:** `django-allauth[socialaccount]`, Django sessions, React context + `useEffect`/`useState`, `fetch` (no SWR for auth — single load on mount)

**Spec:** `docs/superpowers/specs/2026-08-17-auth-design.md`

## Global Constraints

- django-allauth provider: GitHub only. No Google, GitLab.
- Session cookie: `HttpOnly=True`, `SameSite=Lax`.
- Owner = first scanner. Subsequent scans do not change owner.
- `visibility` field stored, not used in v1 (always `"public"`).
- Migration name: `0005_projectmap_owner_visibility`.
- Frontend env var for backend URL: `VITE_BACKEND_URL` (default `http://localhost:8000`).
- No CSRF middleware — not currently in the stack; do not add it.
- All API endpoints return JSON. No HTML error pages from graph views.
- `pm.owner = None` → any authenticated user can write (legacy/unclaimed project).
- `list_project_maps` filters by `owner = request.user` only (no null-owner projects in list).

```python
@api_view(["GET"])
def auth_me(request):
    if not request.user.is_authenticated:
        return Response(status=status.HTTP_401_UNAUTHORIZED)
    social = request.user.socialaccount_set.filter(provider="github").first()
    avatar_url = social.extra_data.get("avatar_url", "") if social else ""
    return Response({
        "id": request.user.id,
        "username": request.user.username,
        "avatar_url": avatar_url,
    })


@api_view(["POST"])
def auth_logout(request):
    if not request.user.is_authenticated:
        return Response(status=status.HTTP_401_UNAUTHORIZED)
    django_logout(request)
    return Response({"ok": True})
```

```typescript
import { createContext, useContext, useState, useEffect } from "react";
import type { ReactNode } from "react";
import { fetchMe, logout as apiLogout } from "../services/api";
import type { AuthUser } from "../services/api";

interface AuthContextValue {
  user: AuthUser | null;
  isLoading: boolean;
  logout: () => Promise<void>;
}

const AuthContext = createContext<AuthContextValue>({
  user: null,
  isLoading: true,
  logout: async () => {},
});

export function AuthProvider({ children }: { children: ReactNode }) {
  const [user, setUser] = useState<AuthUser | null>(null);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    fetchMe()
      .then(setUser)
      .catch(() => setUser(null))
      .finally(() => setIsLoading(false));
  }, []);

  const logout = async () => {
    await apiLogout();
    setUser(null);
  };

  return (
    <AuthContext.Provider value={{ user, isLoading, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth(): AuthContextValue {
  return useContext(AuthContext);
}
```
